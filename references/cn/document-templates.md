# 文档模板结构（扩展版 · 17 套章节骨架）

> **本地化标准说明（Localization Standard）**  
> 本套模板中文字节骨架对齐 **GB/T 8567-2006《计算机软件文档编制规范》**。章节命名与顺序按该标准对应条款组织，供生成文档时套用。

> **作者获取优先级（Author Acquisition Priority）**  
> 生成文档时，作者字段按以下优先级获取：  
> 1. **当前用户**：调用 Skill 的用户标识（`$env:USERNAME` / `whoami`）  
> 2. **Git 提交作者**：目标项目最近提交作者（`git log -1 --format=%an`）  
> 3. **置空**：若以上均无法获取

> **版本差异日志（Version Diff Log）**  
> 当存在历史版本文档时，Skill 会在每个新文档末尾自动追加差异日志章节，按以下格式记录与上一版本的变更：  
> - 🟢 **新增**：新文档中有而旧文档中没有的内容  
> - 🟡 **修改**：新旧文档中均有但内容有变化的部分  
> - 🔴 **删除**：旧文档中有而新文档中已移除的内容  
> 若无差异，注明"与上一版本无差异"；若为全新文档，标记为"全新文档"。

> **DOCX 输出格式（DOCX Output Format）**  
> 默认生成 Markdown（`.md`）。当提示词包含 `docx`、`word` 或 `.docx`（不区分大小写）时生成 `.docx`，先按 Markdown 模板生成再经 `pandoc` 转换；未安装 pandoc 则回退 Markdown 并提示 `winget install JohnMacFarlane.Pandoc`。

> **版本号参考（Version Reference）**  
> 版本号生成规则见 `references/cn/git-version-info.md`：有 Git 为 `1.{yy}.{Mdd}.{git提交次数}`；无 Git 为 `1.{yy}.{Mdd}.{hmm}`。
