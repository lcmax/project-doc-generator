# 【Skill 创作】全自动项目文档生成器，一键产出全套标准项目文档
> 版本：1.26.731.20 | 更新日期：2026-07-31 | 作者：李荣起

## 1、Skill简介
这是一款**项目代码全自动文档生成器**Skill，可自动解析项目代码结构与业务逻辑，一键批量生成需求规格、概要设计、数据库设计、API文档等全套标准化文档，适配开发、运维、项目交付人员快速补齐项目资料、规范文档归档使用。

**v1.26.731.20 新增能力**：
- 🎯 **交互式参数收集**：生成前通过提问确认项目名、语言、范围、格式、作者，兼容 8 种 IDE（Trae/Trae Work/Claude Code/Codex/Cursor/OpenCode/WorkBuddy/CodeArts）的三级降级策略（原生提问 → 文本提问 → 默认值）
- 🌐 **多语言按需生成**：支持仅中文 / 仅英文 / 双语三种模式，按需裁剪目录创建、归档与差异对比
- 📦 **生成范围选择**：支持全部 7 套或自选子集（如"1,3,5"），部分生成时在文档头部标注
- 👤 **作者优先级链**：项目级规则（李荣起）→ 当前用户 → Git 提交作者 → 置空
- ✅ **动态检查清单**：按用户选择的语言与范围动态渲染，取代原硬编码清单

## 2、使用场景
日常开发中经常遇到新项目缺全套文档、老项目无留存资料、交付前临时补写各类设计文档的问题；手动逐篇写需求、设计、库表、API、部署手册耗时费力，格式不统一、版本混乱难追溯。
有了这个Skill后，只需传入项目代码/项目目录，就能自动按规范生成整套文档、自动生成专属版本号、附带变更日志，省去手动撰稿、排版、版本整理的全部重复工作。

## 3、创作过程
1. 核心定位设定：触发关键词为**生成项目文档、形成项目文档**，适配新项目搭建、老项目补档、项目交付归档三大核心场景。
2. 逻辑流程搭建：先解析项目目录与核心代码，识别架构、领域模型、业务逻辑；再自动获取Git版本信息或本地时间戳，按固定规则生成标准化版本号。
3. 文档体系配置：预设7大标准文档模板，包含需求规格、概要设计、详细设计、数据库设计、API文档、测试计划、部署&用户手册。
4. 规范标准化：统一文档头部格式（项目名/作者/日期/版本）、固定变更日志表格模板，自动生成版本历史与变更记录，支持版本管理追溯。
5. 目录规则配置：自动在项目根目录创建`Doc/项目名`专属归档目录，已有文档可自动参考兼容。
6. **交互式参数收集**（v1.26.731.20 新增）：生成前通过 IDE 原生提问工具或文本提问，收集项目名、语言（中文/英文/双语）、生成范围（全部/子集）、输出格式（Markdown/DOCX）、作者偏好，并按选择动态裁剪后续归档与差异对比流程。
7. **多 IDE 兼容策略**（v1.26.731.20 新增）：针对 Trae/Trae Work/Claude Code 优先使用 AskUserQuestion 工具；针对 Codex/Cursor/OpenCode/WorkBuddy/CodeArts 采用文本提问降级方案，确保跨 IDE 体验一致。

## 4、使用步骤
1. 调用该Skill，输入指令：**帮我生成项目文档**/**形成项目文档**；
2. 上传项目代码文件或告知项目目录结构；
3. Skill 自动解析代码、获取Git/本地时间版本信息；
4. **交互式确认**（v1.26.731.20 新增）：Skill 通过提问确认项目名称、文档语言（仅中文/仅英文/双语）、生成范围（全部7套/自选子集）、输出格式（Markdown/DOCX）、作者，回复"跳过/默认"即使用默认值；
5. 按确认结果创建专属文档目录，依次生成对应语言与范围的标准文档；
6. 输出带版本号、变更日志的完整文档套件，直接可落地使用。
